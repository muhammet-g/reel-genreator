# Inert legacy reference

This archive preserves the former Community Reels / HyperFrames implementation,
manuals, skills, tests and provider prompts. It is not imported, executed or read
by the default Remotion workflow. Skills here are outside discovery.

The original complete runnable layout is recoverable at Git commit `f5dcf75`.
Checkpoint `dbe1d0c` contains both the independent verified Remotion core and the
original legacy layout. Use a separate Git worktree at that revision to investigate
old builders. Archived scripts are not supported entry points in the new layout.

Project media, prior exports, examples and assets were preserved. Legacy removal
was not destructive: automatic approval rejected the proposed broad deletion, so
these files were isolated instead. Permanent deletion can be a separately reviewed
operation; it is unnecessary for running Remotion.
