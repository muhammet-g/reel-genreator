# Paper style reference — initial collection

At the creator's request, the local paper reference is organized under
[projects/style-references/paper/README.md](../projects/style-references/paper/README.md).
Read it on demand for a paper-style task, then the relevant element or sound entry.

It includes actual Aleppo V3 component source snapshots, frame/sample timings,
reviewed frame sequences, recorded CC0 Foley with provenance/hashes, design
principles and an authoring worksheet. It is an adaptable reference, not a mandatory
template, an engine API or a creator-approved quality baseline. V1/V2 rejections
and V3 acceptance/listening limits are retained. Brand identity stays project-specific.

The local collection belongs to ignored projects/ and is not included in a Git clone.
This pointer remains discoverable; if the collection is unavailable, recover or
rebuild it from the named project evidence rather than claim its assets are present.
